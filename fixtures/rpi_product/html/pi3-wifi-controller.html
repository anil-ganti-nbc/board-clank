Raspberry Pi 3 Model B

The Raspberry Pi 3 Model B is the third-generation Raspberry Pi single-board computer.

Specification

  • Broadcom BCM2837 quad-core Cortex-A53 64-bit SoC @ 1.2GHz
  • 1GB LPDDR2 SDRAM
  • 2.4GHz 802.11n wireless LAN using BCM43438
  • Bluetooth 4.1, BLE
  • 10/100 Ethernet
  • 4 × USB 2.0 ports
  • Full-size HDMI
  • CSI camera port
  • DSI display port
  • 40-pin GPIO header
  • microSD card slot

The onboard BCM43438 connectivity controller provides Wi-Fi and Bluetooth. It is not the application processor.
