STAR64

The STAR64 single-board computer features the StarFive JH-7110 SoC. This SoC combines a quad-core SiFive U74 RISC-V 64bit CPU with an IMG BXE-4-32-G52-2EE GPU. It is equipped with 8GB LPDDR4 system memory, onboard 128Mb QSPI NOR Flash, an optional eMMC module (up to 128 GB) and a microSD slot for booting. The board is equipped with a dual band Wi-Fi and Bluetooth with a flex antenna, a PCIe x1 open ended slot, 1x USB 3.0 type A Host, 3x USB 2.0 Host, dual Gigabit Ethernet.

Features and Specifications

  • SoC: StarFive JH-7110 (quad-core SiFive U74 RISC-V 64-bit CPU, IMG BXE-4-32-G52-2EE GPU)
  • Memory: 8GB LPDDR4
  • Storage: optional eMMC module (up to 128GB), microSD slot, onboard 128Mb QSPI NOR Flash
  • Networking: dual Gigabit Ethernet; dual band Wi-Fi and Bluetooth
