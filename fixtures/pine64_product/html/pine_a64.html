PINE A64 (+)

The PINE A64 (+) is PINE64's first Single Board Computer powered by Allwinner's A64 quad-core ARM Cortex A53 64-Bit SoC. There are many Operating Systems available for the PINE A64 (+).

Features and Specifications

  • SoC: 4 x ARM Cortex A53 cores @ 1.152 GHz (Allwinner A64)
  • GPU: ARM Mali 400 MP2 GPU
  • Memory: DDR3 RAM (up to 2GB)
  • Networking: Gigabit Ethernet; optional 802.11 b/g/n WiFi and Bluetooth 4.0 module
