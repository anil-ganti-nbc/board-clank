BPI-M5 Pro

Overview

BPI-M5 Pro is the latest generation high performance SBC. SoC: Rockchip RK3576. CPU: Integrated with four Cortex-A72 cores @ 2.2GHz and four Cortex-A53 cores @ 1.8GHz. GPU: ARM Mali G52.

Hardware

Decoding RAM: 8/16GB 32-bit LPDDR4x, default is 8GB. RK3576 supports a maximum of 16GB. Flash: 32/64/128GB eMMC, default is 64GB eMMC.

Networking

2x 2.5G Ethernet. Support WiFi 6 and BT5.3.

USB

1x USB 3.0 + 2x USB 2.0. PCIe 3.0 x4 NVMe SSD support.
