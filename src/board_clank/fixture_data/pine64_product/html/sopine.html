SOPINE

The SOPINE is a compute module powered by the same Quad-Core ARM Cortex A53 64-Bit Processor used in the PINE A64 with 2G LPDDR3 RAM memory, Power Management Unit, SPI Flash and integrated MicroSD Slot.

Features and Specifications

  • SoC: 4 x ARM Cortex A53 cores @ 1.152 GHz (Allwinner A64)
  • Memory: LPDDR3 RAM (2GB)
