Quartz64-Zero

The Quartz64-Zero SBC is featuring the Rockchip RK3566T SoC in a smaller PCB form factor. This SoC combines a quad-core, ARM Cortex-A55 1.6GHz CPU with a Mali-G52-2EE GPU. It is equipped with 1GB LPDDR4 system memory, an optional eMMC module (up to 128GB) and microSD slot for booting. The board is equipped with a Wifi/BT with flex antenna.

Features and Specifications

  • CPU: QUAD 64-bit ARM Cortex-A55 CPU (Rockchip RK3566T)
  • Memory: 1GB LPDDR4 System Memory
  • Storage: optional eMMC module, microSD slot
  • Communication: 802.11 B/G/N/AX Wi-Fi, Bluetooth 5.4
