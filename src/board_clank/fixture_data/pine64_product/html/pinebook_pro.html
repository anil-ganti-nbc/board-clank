Pinebook Pro

The Pinebook Pro is a Linux and *BSD capable ARM laptop, featuring a Rockchip RK3399 hexa-core SoC, 4GB of LPDDR4 system memory, and a 1080p IPS panel.

Features and Specifications

  • SoC: 4 x ARM Cortex A53 cores @ 1.4GHz + 2 x ARM Cortex A72 cores @ 1.8 GHz (Rockchip RK3399)
  • Memory: 4GB LPDDR4 RAM
