ROCK64

The ROCK64 is a credit card sized Single Board Computer powered by Rockchip RK3328 quad-core ARM Cortex A53 64-Bit Processor and support up to 4GB 1600MHz LPDDR3 memory. It provides an eMMC module socket, MicroSD Card slot, Pi-2 bus, Pi-P5+ bus, USB 3.0 and many others peripheral devices interface.

Features and Specifications

  • SoC: 4 x ARM Cortex A53 cores @ 1.5 GHz (Rockchip RK3328)
  • Memory: LPDDR3 RAM (up to 4GB)
  • Networking: Gigabit Ethernet
