Raspberry Pi Compute Module Zero

Compute Module Zero is a System on Module built around the RP3A0 chip, a custom-built system-in-package designed by Raspberry Pi.

Specification

  • Processor: RP3A0 system-in-package, 1GHz quad-core 64-bit Arm Cortex-A53 CPU
  • Memory: 512MB LPDDR2 SDRAM
  • Optional 2.4GHz 802.11 b/g/n Wi-Fi and Bluetooth 5.0, BLE
  • Optional 8GB or 16GB eMMC flash storage
  • Compute Module Zero Lite variant without eMMC

Official PIP SKUs observed as references, not boards: SC2230 SC2231 SC2232 SC2233 SC2234 SC2235
