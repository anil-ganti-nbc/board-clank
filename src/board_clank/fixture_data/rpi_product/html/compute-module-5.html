Raspberry Pi Compute Module 5

Compute Module 5 delivers the power of Raspberry Pi 5 in a module form factor.

Specification

  • Broadcom BCM2712 quad-core 64-bit Arm Cortex-A76 SoC @ 2.4GHz
  • Options for 2GB, 4GB, 8GB, or 16GB LPDDR4-4267 SDRAM with ECC
  • Options for 0GB (Lite), 16GB, 32GB or 64GB eMMC flash memory
  • Options for certified radio module containing 2.4 GHz / 5.0 GHz IEEE 802.11 b/g/n/ac wireless and Bluetooth 5.0
  • Gigabit Ethernet PHY supporting IEEE 1588
